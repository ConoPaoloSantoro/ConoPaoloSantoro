## 🚀 Selected Projects

### 🔐 [Malware Detection & Adversarial Robustness](https://github.com/mpanico20/malware-detection)

Machine Learning and Deep Learning approaches for PE malware detection, cross-dataset generalization and adversarial robustness analysis.

### 🛡️ [Penetration Testing & System and Network Security](https://github.com/ConoPaoloSantoro/penetration-testing-system-network-security)

Internal penetration testing project performed in a controlled multi-host laboratory environment.

The assessment covered **reconnaissance, service enumeration, vulnerability assessment, exploitation, privilege escalation, post-exploitation and remediation** across Linux and Windows systems.

The work included CVSS-based vulnerability reporting and hands-on use of tools such as **Nmap, Burp Suite, SQLmap, Mimikatz, Metasploit/Meterpreter, Rubeus, Impacket, John the Ripper, Netcat and ffuf**.


### ☁️ [Secure ML Kubernetes Deployment](https://github.com/ConoPaoloSantoro/secure-ml-kubernetes-deployment)

Secure and scalable deployment of a machine-learning web application using **Docker and Kubernetes**, including container vulnerability assessment and horizontal autoscaling.

### 🔑 [Secure Digital Credentials Protocol](https://github.com/ConoPaoloSantoro/secure-digital-credentials-protocol)

Digital credential protocol based on **PKI, X.509 certificates, ECDSA, RSA, OTP and OpenSSL**.

### ⛓️ [ReviewOnChain](https://github.com/ConoPaoloSantoro/review-on-chain)

Decentralized review platform built with **Ethereum smart contracts, decentralized identities and verifiable credentials**, including credential revocation, voting and security analysis.

### 📊 [World Cup Big Data Analysis](https://github.com/ConoPaoloSantoro/world-cup-big-data-analysis)

Distributed analysis of FIFA World Cup data using **Hadoop MapReduce and Apache Spark**.
